# PPT 数据图表美化页

把用户给的原始数据图表，重排成一页"数据保真 + 暖调汇报风"的 16:9 PPT 数据图表页，并产出对应的 .pptx 文件。

## 最高优先级硬约束（不可违背）

这三条是红线，任何一条违反都必须重做：

1. **数据零篡改**：
   - 用户给的每一个数字、分类名、单位、时间标签、类别顺序，必须 100% 照搬
   - 不允许四舍五入、不允许"凑整"、不允许把 140 写成"约 140"
   - 不允许调换 bar / slice 的排列顺序（原图什么顺序就什么顺序）
   - 不允许增减数据点、不允许把缺失月份补 0
   - 数据标签上的数字必须和原始数据逐字一致
2. **图表语义不改**：原图是趋势图就还是趋势图，原图是占比图就还是占比图。只有原图类型和数据形态明显错配（见 [`references/chart-decision.md`](references/chart-decision.md)）时才建议换图，且必须先告知用户理由、得到同意后再换。
3. **看不清就问**：用户给的图里有看不清的数字、单位、图例含义，先问用户，不要猜、不要编。

## 核心视觉法则

做数据图最容易犯的错是把每根 bar / 每个 slice 都涂不同颜色，结果观众注意力被稀释。正确做法：

1. **颜色是信息，不是装饰**：整张图只用一个主色 + 同色系明度渐变，只给最关键的那一个数据点（最大值 / 异常值 / 用户点名要强调的点）用最深一档颜色突出，其余用浅色。不要每根 bar 一个颜色。
2. **去装饰化**：删掉默认子标题（"销售额""手机费用情况/元"这种）、删掉默认图例（数据标签直接标在图形上后图例是冗余的）、删掉纵轴竖线和多余网格线、去掉 3D 效果和粗描边。
3. **数据标签直标**：数值直接写在图形旁边/上面/内部，不要让观众对着坐标轴估。
4. **数据故事化标注（最重要）**：光画数字不够，必须把数据里的"故事"直接标在图上——
   - 两组对比数据（今年vs去年、实际vs目标）：每个类别旁边标注**变化幅度**（+X% / -X%），涨用赤陶棕↑，跌用深灰棕↓
   - 趋势数据（折线）：标注**峰值、谷值、最大涨幅、最大跌幅**，用箭头或文字提示
   - 占比数据：标注**最大块占比**和**与第二名的差距**
   - 波动大的序列：标出**波动率**（最高-最低 / 均值）
   - 让观众扫一眼就知道"发生了什么变化"，不用自己算
5. **暖调汇报风**：配色锁定 [`references/warm-palette.md`](references/warm-palette.md) 的暖米白 + 深驼棕 + 赤陶棕色系，不要亮蓝、亮粉、草绿等可爱马卡龙色。

## 工作流

### 第 1 步：读数据，列原始数据清单 + 分析数据故事

通读用户给的图 / 表 / 文字，逐条列出：

- 图表类型（折线 / 饼 / 条形 / 柱状 / 雷达 / 气泡 / 树图…）
- 每个分类或时间点的名字
- 每个数值（带单位）
- 类别轴顺序（从左到右 / 从上到下）
- 用户有没有点名要强调哪一个数据点
- 原图标题（作为 PPT 页面标题候选）

列完原始数据后，**必须额外做一遍数据故事分析**（这一步不能省）：

1. **算变化幅度**：如果是两组对比数据（2024 vs 2025、实际 vs 目标、今年 vs 去年），逐个类别算变化率：`(新值-旧值)/旧值 × 100%`，标注涨跌幅
2. **找关键节点**：趋势数据找峰值、谷值、最大单期涨幅、最大单期跌幅
3. **找异常点**：有没有哪个类别明显偏离其他类别（特别高 / 特别低）
4. **定图表主角**：这组数据最想让观众记住什么？是"涨了"还是"跌了"还是"谁是老大"？主角决定哪个数据点用强调色

把这些洞察写进草稿，后面 prompt 里必须标到图上。

列完后**逐项和用户给的原始材料对数**，对不上就问用户，不要往下走。

### 第 2 步：判断图表类型是否需要换

按 [`references/chart-decision.md`](references/chart-decision.md) 的决策表判断：

- 原图类型和数据形态匹配 → 保留原图类型，直接进第 3 步
- 原图类型和数据形态明显错配 → 用一句话告诉用户："你给的是 X 图，但数据是 Y 形态，换成 Z 图更清楚，可以吗？"等用户同意再换；用户不同意就按原图类型美化

**特别注意——两组对比数据的默认展示方式**：
- 如果数据是两组对比（今年vs去年、实际vs目标），且类别 ≤ 6 个，**默认用卡片式同比展示**（每个类别一张卡片，大箭头+大百分比做主角，小柱子在下面），不要用普通分组柱状图
- 只有类别 > 6 个卡片排不下时，才回退到普通分组柱状图

**不要因为"Z 图更好看"就换图。**

### 第 3 步：选配色

从 [`references/warm-palette.md`](references/warm-palette.md) 选主色。默认用深驼棕 `#8B6F47` 做主色，赤陶棕 `#B5543F` 做强调色。用户指定品牌色时，把饱和度压低 30% 融入暖调体系。

### 第 4 步：按图表类型套美化模板

读 [`references/beautify-playbook.md`](references/beautify-playbook.md)，按选定的图表类型套对应的美化手法（面积渐变方向、环形图怎么挖空、条形图空心目标框怎么画、阴影椭圆参数等）。

### 第 5 步：调 image_gen 出图

调用 `image_gen`，参数：
- `model_version=seedream_5.0_flash`
- `width=2048, height=1152`（16:9）

prompt 按 [`references/prompt-recipe.md`](references/prompt-recipe.md) 的模板拼。**必须**在 prompt 里：

- 逐个列出所有数据点（分类名 + 数值 + 单位），明确写"数字必须和给出的完全一致，不得四舍五入、不得编造"
- 写清楚图表类型和美化手法
- 写清楚配色（具体色值或色感描述）
- 明确写"文字使用简体中文，不要乱码或伪文字"
- 明确写"无默认图例、无多余子标题、无 3D 效果"

### 第 6 步：自检数字 + 检查洞察标注

出图后逐字核对：

1. 每个数据标签的数字和用户原始数据**逐字一致**
2. 分类名、月份名、单位都对
3. 最大值/最小值位置和原图一致（不能 AI 自己改了峰值）
4. 没有出现多余的图例、多余的标题、乱码伪文字
5. 颜色在暖调配色盘内，没有跳出色系
6. **数据故事标注到位**：变化幅度（+X%/-X%）、关键节点（峰值/谷值）都标在图上了，不是光画了柱子/线

任何一条不过，在 prompt 里加重申后重新生成。

### 第 7 步：生成 .pptx 交付

图片确认无误后，用 ppt skill 建一页飞书幻灯片，把这张图表图作为整页主图插入（占满 16:9 画布，四周留少量白边），然后导出 .pptx。

具体操作：
1. 先把生成的图表图下载到本地
2. 按 ppt skill 流程：`slides +create` 建空白幻灯片 → `+media-upload` 上传图片拿 file_token → `+add-slide` 写一页 XML（整页放这张图）→ 截图验收 → `drive +export` 导出 .pptx
3. 用 `present_files` 把图片和 .pptx 一起交付

## 资源导航

- **[`references/chart-decision.md`](references/chart-decision.md)**：图表类型决策表 + 什么情况才允许换图 + 每种图的适用/不适用场景。第 2 步必读。
- **[`references/warm-palette.md`](references/warm-palette.md)**：暖调汇报色盘具体色值 + 渐变参数 + 字体层级规则。第 3 步必读。
- **[`references/beautify-playbook.md`](references/beautify-playbook.md)**：每种图表（面积折线 / 环形占比 / 条形对比 / 雷达 / 气泡 / 树图）的具体美化手法细节。第 4 步必读。
- **[`references/prompt-recipe.md`](references/prompt-recipe.md)**：给 image_gen 的 prompt 结构骨架 + 每种图表的完整正例 + 常见失败反例。第 5 步照着填。

## 交付

最终用 `present_files` 交付两样东西：
1. 16:9 图表图片（2048×1152 PNG）
2. 对应的 .pptx 文件

交付时用 2–3 行字说明：选了哪种图表类型、用了哪组暖色、数字已逐项核对无误。不要附冗长设计说明。
