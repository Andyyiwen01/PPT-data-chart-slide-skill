# image_gen Prompt 配方

## 通用骨架

每次拼 prompt 按这个结构填：

```
一张 16:9 横版 PPT 数据图表页，暖米白背景（#FAF6F0），整体咨询汇报风。

页面布局：[图表类型]，居中放置，四周留白。

图表内容：
[逐个列出数据点：分类名 → 数值 → 单位，顺序和原图一致]

数据洞察标注（必须标在图上）：
[列出这组数据的关键洞察：涨跌幅度、峰值谷值、异常点等]

样式细节：
- 主色：深驼棕 #8B6F47
- 强调色：赤陶棕 #B5543F（涨/关键点用）
- 跌色：深灰棕 #6B5D4F（下跌用）
- 文字：深炭灰棕 #3D352E，简体中文，无乱码
- [对应图表类型的具体美化手法，从 beautify-playbook.md 抄]

硬性要求：
- 所有数字必须和上面给出的完全一致，不得四舍五入、不得编造、不得调整顺序
- 不要默认图例、不要多余子标题、不要 3D 效果、不要鲜艳马卡龙色
- 所有文字清晰可读，不溢出画布
```

## 正例 1：面积折线图（话费缴费记录）

```
一张 16:9 横版 PPT 数据图表页，暖米白背景（#FAF6F0），整体咨询汇报风。

页面布局：面积折线图居中，四周留白，图表在一个带极浅暖灰边框的白色圆角卡片里，卡片下方有一条柔化椭圆阴影。

图表内容（2024年手机话费缴费记录，单位：元）：
1月 67，2月 64，3月 45，4月 70，5月 68，6月 89，7月 90，8月 104，9月 140，10月 120，11月 110，12月 125。

样式细节：
- 折线：深驼棕 #8B6F47，线宽适中
- 面积填充：从折线向下渐变，深驼棕 40% 不透明度渐变到完全透明
- 每个数据点画一个深驼棕实心小圆点，数值标签直接标在圆点正上方
- 9月是最大值 140，那个圆点用赤陶棕 #B5543F 突出
- x 轴月份标签写在底部（1月到12月），不要 y 轴刻度线和数字
- 不要横向网格线、不要默认图例、不要顶部子标题
- 页面顶部大标题："2024年手机话费缴费记录"，深炭灰棕 #3D352E 粗黑体

硬性要求：
- 每个数字必须和上面列出的完全一致，不得四舍五入
- 文字使用简体中文，不要乱码或伪文字
- 所有文字清晰可读，不溢出画布
```

## 正例 2：环形图（各地区销售额）

```
一张 16:9 横版 PPT 数据图表页，暖米白背景（#FAF6F0），整体咨询汇报风。

页面布局：环形图居中偏右，左侧留空，图表在一个带极浅暖灰边框的白色圆角卡片里，卡片下方有柔化椭圆阴影。

图表内容（各地区销售额占比）：
A地区 41%，B地区 25%，C地区 20%，D地区 6%，E地区 5%，F地区 3%。

样式细节：
- 环形图 donut 样式，中间挖空
- A地区 41% 是最大块，用深驼棕 #8B6F47 实心，向外偏移一点点突出
- B地区 25% 用同色系中明度
- C地区 20% 用同色系浅明度
- D/E/F 地区用同色系最浅明度
- 每个色块上直接标注："A地区 41%" 等文字，深色块上用白色字，浅色块上用深炭灰棕字
- 中心挖空的白色圆里：放一个极简钱袋图标 + 文字"各地区 销售额"
- 不要底部图例、不要 3D 效果、不要每块不同颜色

硬性要求：
- 每个百分比数字必须和上面列出的完全一致（41、25、20、6、5、3）
- 文字使用简体中文，不要乱码或伪文字
```

## 正例 3：条形图（实际 vs 目标）

```
一张 16:9 横版 PPT 数据图表页，暖米白背景（#FAF6F0），整体咨询汇报风。

页面布局：横向条形图居中，四周留白，图表在一个带极浅暖灰边框的白色圆角卡片里。

图表内容（产品完成量对比，单位：件）：
产品1：实际 24822，目标 30000
产品2：实际 39562，目标 45000
产品3：实际 50120，目标 55000
产品4：实际 61001，目标 68000
产品5：实际 69545，目标 79000
产品6：实际 85745，目标 91000
产品7：实际 100032，目标 116500
产品8：实际 120120，目标 135000

样式细节：
- 实际完成量：深驼棕 #8B6F47 实心横条，数值直接标在条左端（白色字）
- 目标完成量：暖灰褐 #D4C4B0 空心矩形边框（无填充），数值标在框右端
- 产品名写在最左边
- 底部图例：深驼棕方块 = "实际完成量"，空心方块 = "目标完成量"
- 不要 y 轴线、不要横向网格线

硬性要求：
- 每个数字必须和上面列出的完全一致，不得四舍五入
- 产品顺序从上到下必须和列出的一致（产品1在最下，产品8在最上）
- 文字使用简体中文，不要乱码或伪文字
```

## 正例 4：卡片式同比展示（两组对比首选）

```
高级商务汇报风格数据卡片式柱状图，暖米白背景 #FAF6F0。

页面布局：4个产品卡片从左到右并排排列，每个卡片是白色圆角矩形。

每个卡片结构（从上到下）：
1. 卡片顶部一条彩色横条
2. 卡片上半部分：大箭头 + "同比增长/下降" + 超大百分比数字（百分比是最大视觉元素）
3. 卡片下半部分：两根小柱子，柱顶标数值
4. 卡片底部标产品名

4个产品数据：
抗衰精华：顶部赤陶棕横条，向上箭头，"同比增长 +75%"（赤陶棕超大粗体），柱子480和821
补水面膜：顶部赤陶棕横条，向上箭头，"同比增长 +45%"，柱子760和1094
身体乳：顶部赤陶棕横条，向上箭头，"同比增长 +15%"，柱子750和870
老式气垫霜：顶部深灰棕横条，向下箭头，"同比下降 -50%"（深灰棕超大粗体），柱子1220和610

左上角标题："各产品销量同比变化（2024 vs 2025）"。
底部图例：深驼棕=2024年，赤陶棕=2025年。
所有数字正确，简体中文无乱码。
```

```
左上角标题："各产品销量对比（2024 vs 2025）"，深炭灰棕粗黑体。

X轴底部从左到右4个产品："抗衰精华" "补水面膜" "身体乳" "老式气垫霜"。

每个产品下面两根柱子：
第一根（2024年）：深驼棕 #8B6F47 实心，柱顶标数值
第二根（2025年）：赤陶棕 #B5543F 实心，柱顶标数值

数据（务必逐字正确）：
抗衰精华：2024=470，2025=820
补水面膜：2024=750，2025=1080
身体乳：2024=740，2025=870
老式气垫霜：2024=1220，2025=600

数据洞察标注（必须标在图上）：
抗衰精华上方："↑ +74%"，赤陶棕色
补水面膜上方："↑ +44%"，赤陶棕色
身体乳上方："↑ +18%"，赤陶棕色
老式气垫霜上方："↓ -51%"，深灰棕 #6B5D4F

底部图例：深驼棕方块="2024年销量"，赤陶棕方块="2025年销量"。
白色圆角卡片底，下方柔和阴影。无网格线，无y轴刻度。
简体中文，清晰无乱码。
```

## 常见失败反例（这些写法要避免）

**反例 1：把数据留给 AI 自己算**
> ❌ "画一个各地区销售额饼图"
> ✅ "画一个各地区销售额环形图：A地区 41%，B地区 25%，C地区 20%，D地区 6%，E地区 5%，F地区 3%"

**反例 2：用模糊描述代替具体数字**
> ❌ "1月到12月的话费大概从60涨到140"
> ✅ "1月 67，2月 64，3月 45，4月 70，5月 68，6月 89，7月 90，8月 104，9月 140，10月 120，11月 110，12月 125"

**反例 3：没禁止默认装饰**
> ❌ 不写"不要图例、不要网格线"
> ✅ 明确写"不要默认图例、不要横向网格线、不要顶部子标题"

**反例 4：没强调数字保真**
> ❌ 不写数字保真要求
> ✅ 明确写"每个数字必须和上面列出的完全一致，不得四舍五入、不得编造"

**反例 5：用了可爱色**
> ❌ "用粉色和蓝色的马卡龙色"
> ✅ "主色深驼棕 #8B6F47，强调色赤陶棕 #B5543F，背景暖米白 #FAF6F0"
