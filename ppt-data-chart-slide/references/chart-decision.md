# 图表类型决策表

## 总原则

**默认保留用户原图的图表类型。** 只有当原图类型和数据形态明显错配、会导致信息严重丢失时，才建议换图，且必须先告知用户理由并征得同意。

"更好看"不是换图理由。

## 什么情况算"明显错配"（才考虑换）

| 原图类型 | 数据实际形态 | 错配程度 | 建议换成 |
|---|---|---|---|
| 饼图 | 分类 ≥ 7 类 | 严重：饼图切片太碎，观众无法比较 | 条形图（横向，按数值排序） |
| 饼图 | 数据是时间序列（月份/季度） | 严重：饼图不表达时序 | 面积折线图 |
| 饼图 | 数据是排名对比（A vs B vs C…） | 中等：饼图不表达长度比较 | 条形图 |
| 饼图 | 数据有负值 | 严重：饼图不支持负值 | 条形图（正负双向） |
| 柱状图 | 数据是占比构成（加总=100%） | 中等：柱状图看不出占比关系 | 环形图 |
| 柱状图 | 类别 > 12 个 | 严重：柱子挤成一团 | 条形图（横向） |
| 折线图 | 数据是离散分类对比（无时间轴） | 中等：折线暗示连续趋势，误导 | 柱状图/条形图 |
| 折线图 | 单类别、单时间点快照 | 严重：没有"趋势"可画 | 大数字卡片 + 极简图标 |

## 什么情况不换（直接美化原图）

- 原图是折线趋势图、数据是月份/季度/年度时序 → 保留折线，加面积渐变
- 原图是饼图/环形图、分类 ≤ 6 类、加总=100% → 保留饼图，改环形图 + 单色渐变
- 原图是条形图、类别 ≤ 10 个、两组指标对比 → 保留条形图，改实心+空心
- 原图是雷达图、3–6 个维度、1–5 个对象 → 保留雷达图
- 原图是气泡图、三变量散点 → 保留气泡图
- 原图是树图、分类+权重 → 保留树图

## 各图表适用场景速查

| 数据形态 | 首选图表 | 不适用 |
|---|---|---|
| 时间序列单指标趋势（月份/季度/年） | 面积折线图 | 饼图、雷达图 |
| 时间序列双指标对比 | 面积+折线（一面积一线） | 两条裸折线 |
| 占比构成（各类加总=100%）≤6 类 | 环形图 donut | 柱状图、折线图 |
| 两组指标对比（实际 vs 目标 / 今年 vs 去年）类别 ≤6 | **卡片式同比展示**（大箭头+大百分比+小柱子） | 饼图、普通分组柱状图 |
| 两组指标对比类别 >6 | 分组柱状图（备选） | 卡片式（排不下） |
| 多维度画像（≥3 维度，1–5 个对象） | 雷达图 | 饼图、条形图 |
| 三变量散点（x, y, 大小） | 气泡图 | 柱状图、饼图 |
| 分类+权重层级 | 矩形树图 treemap | 表格、饼图 |
| 排名对比（A>B>C…） | 条形图（横向排序） | 饼图 |

## 换图流程

1. 在草稿里写下：原图类型 = X，数据形态 = Y，错配点 = Z
2. 用一句话告诉用户："你给的是 X 图，但数据是 Y 形态，Z 这个信息在 X 图上看不出来，换成 W 图更清楚，可以吗？"
3. 用户同意 → 按 W 图美化
4. 用户不同意 → 按 X 图美化，但在交付说明里提一句"这个数据形态其实更适合 W 图"
