# PPT Data Chart Slide（PPT 数据图表美化页 Skill）

> 把用户给的原始数据图表（截图 / 数据表 / 文字描述的数据），按**数据保真 + 高级暖调汇报风**美化，重排成一张 **16:9 横版 PPT 数据图表页**，并输出在线幻灯片导出的 **.pptx** 文件。

适用于 AI 助手（如豆包等支持 Skill 机制的智能体）的数据图表美化任务。用户说「把这张折线图/饼图/柱状图做得好看点、高级一点、汇报用」「帮我把这个数据图改成 PPT 页」时，本 Skill 指导模型完成**数据清点 → 故事洞察 → 图表决策 → 暖调配色 → 出图 → 自检 → 导出 .pptx** 的完整流程。

---

## 🔴 最高优先级硬约束（红线）

| # | 红线 | 说明 |
|---|---|---|
| 1 | **数据零篡改** | 每个数字、分类名、单位、时间标签、类别顺序 100% 照搬；不四舍五入、不凑整、不调顺序、不增减数据点、不给缺失月份补 0 |
| 2 | **图表语义不改** | 趋势图还是趋势图、占比图还是占比图；只有类型与数据形态**明显错配**（见 `references/chart-decision.md`）才建议换图，且必须说明理由、征得同意 |
| 3 | **看不清就问** | 图里有看不清的数字、单位、图例含义，先问用户，不猜不编 |

## ✨ 核心视觉法则

1. **颜色是信息，不是装饰**：整图只用 1 个主色 + 同色系明度渐变，只给最关键的一个数据点（最大值/异常值/用户点名）用最深色突出，不要每根 bar 一个颜色。
2. **去装饰化**：删默认图例、多余子标题、纵轴竖线、多余网格线、3D 效果和粗描边。
3. **数据标签直标**：数值直接写在图形上，不让观众对着坐标轴估。
4. **数据故事化标注（最重要）**：把数据里的「故事」直接标在图上——
   - 两组对比 → 每类标变化幅度 `+X% / -X%`（涨赤陶棕↑，跌深灰棕↓）
   - 趋势数据 → 标峰值、谷值、最大涨幅/跌幅
   - 占比数据 → 标最大块占比、与第二名差距
   - 让观众扫一眼就知道「发生了什么」，不用自己算
5. **暖调汇报风**：暖米白 + 深驼棕 + 赤陶棕色系，拒绝亮蓝/亮粉/草绿等马卡龙色。

将整个 `ppt-data-chart-slide` 文件夹放入你的 Skill 根目录即可：

cp -r ppt-data-chart-slide ~/.doubao/agent_mode/workspace/.user_skills/

## 🧭 使用流程

1. **读数据**：逐条列原始数据清单（图表类型、分类名、数值、单位、顺序、用户点名要点），并**额外做数据故事分析**（变化幅度 / 峰值谷值 / 异常点 / 图表主角）。
2. **判类型**：按 `chart-decision.md` 判断是否换图；两组对比且类别 ≤ 6 时**默认用卡片式同比展示**。
3. **选配色**：默认深驼棕 `#8B6F47` 主色 + 赤陶棕 `#B5543F` 强调色；用户品牌色则降饱和 30% 融入暖调。
4. **套模板**：按 `beautify-playbook.md` 对号入座套美化手法。
5. **出图**：`image_gen`，`width=2048, height=1152`（16:9），`model_version=seedream_5.0_flash`；prompt 逐个列出所有数据点并声明数字保真。
6. **自检**：逐字核对数据标签、分类名、峰值位置；检查无图例/乱码、色系正确、**故事标注到位**。
7. **导出 .pptx**：经 ppt skill 建一页飞书幻灯片，整页插入图表图后导出 .pptx，与图片一起交付。

## 🎨 暖调汇报色盘

| 用途 | 色名 | HEX |
|---|---|---|
| 页面背景 | 暖米白 | `#FAF6F0` |
| 主色（线条/实心条/环形主块） | 深驼棕 | `#8B6F47` |
| 强调色（峰值/最大块/关键点） | 赤陶棕 | `#B5543F` |
| 浅色辅助（渐变末端/空心框） | 暖灰褐 | `#D4C4B0` |
| 文字 | 深炭灰棕 | `#3D352E` |
| 参考线/网格 | 极浅暖灰 | `#E8E0D5` |

**禁止**：亮蓝 `#0066CC`、亮粉 `#FF66B2`、草绿 `#7CCC7C`、明黄 `#FFD700`、纯黑、纯白。

## ✅ 输出规格

- **画幅**：16:9 横版，2048 × 1152 px
- **交付**：图表图片 + .pptx 文件
- **字体**：≤ 2 种（标题粗黑体、数据标签常规黑体）；数据标签 ≥ 28px、类别轴 ≥ 32px、标题 ≥ 56px（2048 画布）
- **风格**：咨询公司暖调汇报风（麦肯锡 / BCG 感），不甜腻、不卡通、不马卡龙

## ❓ 常见问题

**Q：用户数字很乱，能帮忙「优化」吗？**
不能。数据零篡改是红线——数字、顺序、单位 100% 照搬，只能优化呈现方式（配色/版式/标注），不能动数据本身。

**Q：什么时候可以换图表类型？**
只有类型和数据形态明显错配（如饼图塞 7+ 分类、饼图画时间序列）才建议换，且必须先告知理由、经用户同意。

**Q：为什么两组对比默认用卡片式而不是分组柱状图？**
卡片式把「大箭头 + 超大百分比」做成主角，观众一眼看出涨跌和幅度；普通分组柱状图要自己对比两根柱子。类别 ≤ 6 时卡片排得下，> 6 才回退分组柱状图。
